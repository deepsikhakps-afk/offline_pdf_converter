Flatbed - t, no database, no server, no internet needed.

Run: open index.html in Chrome or Edge. (If your browser blocks anything, run
"python -m http.server 8000" in this folder and open http://localhost:8000)

PDF to JPG: choose PDF, tick pages, set quality/resolution, download JPGs or one ZIP.
JPG to PDF: add images, drag to reorder, choose page size/margin, Create PDF.

Bundled libraries (in libs/, so it works offline):
  pdf.js 3.11.174 (Apache-2.0) - renders PDF pages
  jsPDF 2.5.1 (MIT)            - builds PDF files
